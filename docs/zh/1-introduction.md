# 一、引言

12月26日将是国际无产阶级伟大的巨人毛主席诞辰130周年纪念日。中国共产党的领导人毛主席直接并亲自领导了20世纪的两场伟大事件：伟大的中国革命（1949年）和无产阶级文化大革命（1966-1976年）。在这些过程中，他建立并发展了毛主义——马克思主义的新的、第三个和更高的阶段。他继承了马克思、恩格斯、列宁、斯大林的工作，把国际无产阶级的思想推向了最高峰，全面解决了世界无产阶级革命的决定性问题。伟大的中国革命代表了解决如何在殖民地、半殖民地和半封建国家进行无产阶级革命并不断地向社会主义过渡的问题的方案。无产阶级文化大革命解决了无产阶级专政下如何继续进行革命，并朝着金光闪烁的共产主义方向继续前行的问题。从理论上看，毛主义构成了马克思主义整体三个构成部分的质的飞跃。在马克思主义哲学上，毛主席不仅发展了列宁确立的马克思主义认识论，还使其实现了辉煌的飞跃，将矛盾规律确立为唯物辩证法的唯一基本规律。马克思主义政治经济学的关键在于确立社会主义建设的经济规律，以及解决无产阶级和资产阶级之间的矛盾如何继续作为向共产主义过渡阶段的主要矛盾这一历史命题。除此之外，毛主席还建立了官僚资本主义理论，这是帝国主义在殖民地半殖民地通过资本输出而产生的一种资本主义。在此过程中，他发展了列宁主义的帝国主义理论，并展示了帝国主义与被压迫国家大庄园之间的不可分割的关系。在科学社会主义方面，毛主席建立了新民主主义革命的理论，这是殖民地半殖民地国家无产阶级革命的普遍形式，以及它不间断地走向社会主义的理论；如何在无产阶级专政的条件下进行社会主义的阶级斗争，通过连续不断的无产阶级文化革命，发展向共产主义的过渡，避免复辟的危险。此外，它还建立了无产阶级最高形式的军事理论：持久人民战争。今天，成为一名共产主义者比以往任何时候都更需要成为一名马克思列宁毛主义者。因此，国际共产主义者同盟（ICL）发出的在全球范围内庆祝毛泽东主席诞辰130周年的号召具有重大的意义。

同年12月26日，距离国际共产主义者同盟公开宣布成立已满一年，这是由成功的国际毛主义统一会议（UMIC）创建的新的无产阶级国际组织。UMIC是十多年来集中工作、会议、区域会议和国际行动运动的成果。经过这场坚决而崇高的斗争，来自14个国家的15个马克思列宁毛主义政党和组织宣告了国际共产主义者同盟（ICL）的诞生，并向国际无产阶级传达了他们的决定：

> “参加国际毛主义统一会议（UMIC）的马列毛主义政党和组织——遵循伟大列宁创立的第三国际的道路和国际共产主义运动（ICM）的最佳传统——庄严地向国际无产阶级和世界人民宣布，我们做出了诞生新的国际毛主义组织的历史性和跨时代性的决定，该组织建立在三面伟大光荣的红旗下：毛主义、反对修正主义的斗争和世界无产阶级革命。
> 
> 怀着深刻的共产主义信念，我们在此聚集的政党和组织——再次并庄严承诺——重申我们自己，履行国际毛主义统一会议的协议，捍卫和应用国际无产阶级万能的意识形态——马列毛主义。
> 
> 这是在艰苦不懈的斗争中坚定不移的承诺，旨在将毛主义确立为世界革命的唯一指挥和指南，这是唯一深红且永不褪色的旗帜，是无产阶级、被压迫民族和世界人民在向着金色永恒闪耀的共产主义不可阻挡的前进中取得胜利的保证。”
> 
> （国际共产主义者同盟《政治宣言和原则》）[1]

国际毛主义统一会议的召开标志着一个以力量分散和试图重组力量为特征的整个阶段的结束，同时开启了一个激烈的两条路线斗争的新阶段，这场斗争在2022年国际毛主义统一会议协调委员会发布《讨论基础》后贯穿全年。 《共产国际》杂志发表了所有对《讨论基础》的批判和支持立场，推动了一场在国际共产主义运动中久未见的两条路线斗争。国际毛主义统一会议对于与会组织以及未能参加此次盛会的支持者来说，是一个阶段的顶峰。12月26日发表的光辉的《政治宣言与原则》是最高的意识形态成果。2023年1月在数十个国家举行的庆祝活动中的挥舞旗帜行动是国际共产主义者同盟成立的初步实践成果，随后是盛大的五一节庆祝活动、反对修建特万特佩克地峡（墨西哥）洋际走廊的国际运动、对易卜拉欣·凯帕喀亚（土共/马列）牺牲50周年的有力致敬、纪念和颂扬菲律宾同志贝尼托和威尔玛（菲律宾共产党）记忆的运动、在法国示威中释放政治犯的国际主义行动，以及号召民主、反帝和革命力量有力地表明他们对英雄的巴勒斯坦民族抵抗运动的支持，并谴责和反对犹太复国主义以色列国及其在巴勒斯坦人民76年种族灭绝中的罪恶行径。

整整40年前，贡萨罗主席和秘鲁共产党发起了具有挑战性的毛主义运动。国际毛主义统一会议的召开和国际共产主义者同盟的成立成功地完成了这项任务的一个重要阶段，代表着共产主义者在世界团结一致、克服分散、反对修正主义和未来重建光荣的共产国际方向上迈出了决定性的一步。因此，它代表着对帝国主义、修正主义和世界反动派的沉重打击，这些东西迟早会被世界无产阶级革命从地球表面扫除！我们认为，这界革命由两大潮流组成一个是普遍存在于各国的国际无产阶级革命运动，而另一个是存在于殖民地、半殖民地国家的民族解放运动。第一个潮流是地球上所有国家现有的或将要组建和重组的共产党和国际共产主义运动；第二股潮流代表了所有殖民地半殖民地国家的民主革命斗争，这些斗争必须由各自的共产党领导。国际共产主义者同盟的成立，对于世界无产阶级革命两大潮流的革命合流，起到了重要作用。

英雄的巴勒斯坦民族抵抗运动辉煌的革命反攻，给了种族灭绝的犹太复国主义以色列国以沉重打击。在巴勒斯坦民族抵抗运动（哈马斯、伊斯兰圣战组织、解放巴勒斯坦人民阵线和解放巴勒斯坦民主阵线）领导下，巴勒斯坦游击队对以色列占领领土的大胆袭击是世界无产阶级革命的伟大胜利。毕竟，它代表着对犹太复国主义以色列国的占领和扩张主义及其主子——世界人民最大敌人美帝国主义的沉重打击。全世界群众庆祝巴勒斯坦民族抵抗运动的这一伟大胜利，这更有力地成为全球瞩目的焦点：全世界被压迫人民和民族依然存在、在反对帝国主义统治的坚决和流血斗争中燃烧着希望的火种。这些群众要求有坚定的意识形态、政治和军事领导，因此，国际共产主义运动有责任加快他们的斗争步伐，以实现革命阶级斗争的更高形式，即人民战争。

英勇的巴勒斯坦民族抵抗运动、塔利班将美军驱逐出领土的伟大胜利，以及同时反对俄罗斯帝国主义占领和美国和欧盟帝国主义的走狗泽连斯基领导的乌克兰人民的坚持不懈的抵抗，共同确认了一个事实：在帝国主义中，资本主义现阶段的主要矛盾是反对被压迫人民和民族接受帝国主义统治。这面由毛主席在20世纪60年代举起的强大旗帜，在国际共产主义者同盟的《政治宣言和原则》中以精确而有力的方式再次举起：

> “整个资本主义社会进程以**无产阶级与资产阶级之间的矛盾为基本矛盾**。然而，当世界从非垄断资本主义过渡到垄断资本主义——或帝国主义时，世界发展出**三个基本矛盾**：
> 
> 第一个矛盾：一方面是被压迫民族，另一方面是帝国主义超级大国和强国。这是当前时期的**主要矛盾**，同时也是**帝国主义时代的主要矛盾**。
> 
> 第二个矛盾：无产阶级与资产阶级之间。 第三个矛盾：帝国主义内部矛盾。” （国际共产主义者同盟，引自中国共产党）[2]

二十一世纪为民族解放而不懈斗争浪潮的重新兴起，集中体现在巴勒斯坦群众的英勇斗争中。这一浪潮是世界无产阶级革命迫切呼唤毛主义领导的明确体现，因为只有毛主义才能为这场斗争指明方向，并带领它取得反对帝国主义的胜利。正是毛主义通过将矛盾规律确立为唯物辩证法的唯一基本规律，成功地指明了帝国主义在殖民地和半殖民地国家的半封建制度的再生产中维持了民族压迫、促成革命的道理。新民主主义革命是受帝国主义压迫的国家无产阶级革命的普遍形式。只要共产党人支持、直接参与和领导这些斗争，毛主义就会被这些群众所接受。从这个意义上说，秘鲁、土耳其、印度和菲律宾正在进行的以及即将开始的人民战争，构成了推动这些斗争并为其提供正确方向的伟大堡垒。

英勇的巴勒斯坦、阿富汗和乌克兰抵抗运动，尽管为民族半封建或民族资产​​阶级的领导，却自发地通过持久人民战争理论来接近毛主义的假设，并以自己的方式运用它，因为只有这样才能能够给帝国主义以决定性的打击。然而这还不够，这些进程有必要将毛主义视为一种思想政治路线和方向，因为只有这样，他们才能提高反帝国主义的抵抗能力，进行不间断的民族民主革命战争。社会主义革命是打败帝国主义并将其从地球上扫除的唯一可能的途径。然而，这只能通过加强国际共产主义运动，通过各国共产党的组建和重组以发起和发展人民战争实现。关于民族抵抗，共产党人迫切需要支持他们，直接参与其中，从而为他们提供无产阶级的指导。

国际共产主义者同盟的成立是这个意义上的重要一步，因为它在克服分散的危险方面取得了巨大进展，将来自14个国家的15个马克思列宁毛主义政党和组织统一在同一个国际组织中。其中包括秘鲁共产党-PCP和土耳其共产党/马列-TKP/ML，它们正在领导世界上两场非常重要的人民战争。与此同时，国际共产主义者同盟的成立开启了国际共产主义运动两条路线斗争的新阶段。一方面，菲律宾共产党和印度共产党（毛主义）等重要政党领导了非常重要的人民战争，但无法参加今年的国际毛主义统一会议，他们对国际共产主义者同盟的成立及其政治宣言和原则采取了不同的立场。另一方面，一些去年参加了公开的两条路线斗争的组织受邀参加会议的组织，但是故意决定不参加会议并坚持自己的立场。在后者中，有两个组织脱颖而出，它们在最近的过去与阿瓦基安主义和普拉昌达主义非常接近，这两个组织分别是哥伦比亚共产主义工人联盟（马列毛主义）和意大利毛主义共产党。它们继续表达了对国际毛主义统一会议和当时成立的国际共产主义者同盟的批评立场。

围绕国际共产主义者同盟《政治宣言与原则》的两条路线斗争贯穿2023年，是围绕作为国际毛主义统一会议号召的《讨论基础》的两条路线斗争在新层面上的延续。这些立场存在若干差异和细微差别，但其中存在着划定界限的重要分歧：一方捍卫新民主主义革命的有效性以及被压迫民族和人民与帝国主义之间矛盾的首要性；另一方则否认新民主主义革命的关键重要性，并将主要矛盾降至次要地位。

一方面，参加国际共产主义者同盟的政党和组织，加上菲律宾共产党和印共（毛），公开支持无产阶级的红色路线，这完全符合帝国主义阶段和当前时代。另一方面是共工盟（马列毛主义）和意大利毛主义共产党，他们认为帝国主义已经扫除了半殖民地国家的半封建关系，使得新民主主义革命越来越过时。前者代表着对毛主义的捍卫，对半殖民地国家新民主主义革命普遍性的捍卫。后者则继续捍卫21世纪的修正主义模式，特别是阿瓦基安主义和普拉昌达主义。共工盟（马列毛主义）更明确，意大利毛主义共产党则更狡猾和隐蔽。

在国际共产主义者同盟历史性地宣告成立的一天后，哥伦比亚共产主义工人联盟（马列毛主义）发表了一份声明，向其基层解释其未参加国际毛主义统一会议的原因。不久之后，他们发表了一份长篇文件，批评了国际共产主义者同盟的15个创始政党和组织，特别是我们的巴西共产党（PCB），指控我们所谓的“宗派主义和左倾主义……”。在这份文件中，共工盟（马列毛主义）特别攻击我们，据他们所说，声称他们在2016年访问巴西期间受到了“粗暴和羞辱性”的对待。我们将在最后驳斥这个恶毒卑鄙的谎言，因为我们认为对国际共产主义运动更重要的是深入探讨共工盟（马列毛主义）对国际毛主义统一会议及国际共产主义者同盟创始政党和组织批评的意识形态、哲学、政治和经济内容。正如贡萨罗主席教导我们的，我们必须将意识形态斗争提升到两条路线斗争的高度，以消除右倾和“左”倾机会主义立场及教条主义，从而粉碎修正主义。共工盟（马列毛主义）攻击国际共产主义者同盟和特别是巴西共产党的文件，因其详细阐述了自身立场，暴露了他们对马列毛主义的理解，从而使我们能够看到他们与修正主义的趋同以及对毛主义的否定。因为，尽管他们自称为“马列毛主义者”，但他们公开否认**矛盾规律**是辩证法的唯一基本规律，否认新民主主义革命对殖民地半殖民地国家的有效性，肯定帝国主义存在所谓的**进步趋势**，否认农民斗争对帝国主义压迫下国家革命的决定性意义。哥伦比亚是世界上土地集中度最高的国家，拥有拉丁美洲最悠久最伟大的农民武装斗争传统之一，而共工盟（马列毛主义）的领导层却声称他们国家几乎没有农民了，哥伦比亚的革命将立即是社会主义革命。

巴西共产党的历程已然走过一个世纪。在将自己建设为真正的无产阶级革命政党的斗争中，主要是在过去近三十年的斗争中，我们经历了非常艰难的历程，以使自己重建为军事化的、坚持马列毛主义，主要是毛主义，以及贡萨罗主席普遍有效性的贡献的革命政党。P.C.B.正处在从自己的历史和国际经验中学习并纠正错误的长期过程中，但我们始终依靠所有国际经验的积极方面，认为：更全面、更严格地解决马克思主义基本问题上的偏差和歪曲不仅是必要的，也是不可避免的，这对于评价无产阶级革命和国际共产主义运动（ICM）的历史经验至关重要，特别是针对当前的这些偏离及其含糊其辞。在本文件中，为了促进关于这些问题的**两条路线斗争**，我们采取论战的形式，因为共工盟（马列毛主义）领导层对国际共产主义者同盟和巴西共产党的批评和攻击，我们将其定性为阿瓦基安主义和托洛茨基主义的立场，以更集中和更明确的方式把它们呈现出来。在全文中，在我们的分析和论证中，我们大量引用了马克思主义经典著作，其中许多内容已经为许多人所熟知，但我们反复引用它们，因为我们认为这些语录在当前的斗争中极其重要，只有大量的引用它们，才能以完全的科学严谨性阐述其概念基础，同时这么做也能关注到所有潜在的读者和对这场斗争感兴趣的人，并致力于吸引日益增长的新一代革命积极分子加入这场斗争中——因为其中许多人肯定仍然缺乏对革命理论更好的掌握。
