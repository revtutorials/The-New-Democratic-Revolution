# 翻译说明

本文是国际上的同志所写的文章，它生动地阐释了世界无产阶级革命和民族民主革命的关系，同时它的阐释是站在被压迫民族的视角上进行的，这对于我们理解人民战争、理解世界无产阶级革命新的伟大浪潮，对于身处帝国主义国家的我们理解无产阶级革命同被压迫国家革命的联系，更好地开展帝国主义国家内无产阶级革命的组织工作、群众运动和武装斗争，都具有十分重要的参考意义。

本文的翻译，进行地十分仓促。这里的中文译本是根据原文的英文译本经机器翻译获得的。译者只对少数词语进行了替换。

本文所涉及到的所有引用，包括但不限于毛主席语录均为原文机翻所得，未由通行资料替换。

译者不对文章内容的准确性负责。

# 西班牙语译者序

我们在此分享我们收到的一份文件。我们将尽快翻译并呈现它，并以纯文本形式上传该文件。

**_全世界无产者，联合起来！_**

巴西共产党的文件《新民主主义革命是世界无产阶级革命的主力》介绍

我们怀着无产阶级的喜悦，出版了**巴西共产党**（P.C.B.）撰写的西班牙语版《新民主主义革命是世界无产阶级革命的主力》。该文件最初于2023年12月26日以葡萄牙语出版。目前的翻译是由我们**哥伦比亚共产党 (红色派)** 进行的，我们意识到需要将这项宝贵的工作提供给西班牙语读者。

在这项重要的理论和意识形态工作中，**巴西共产党**坚定地捍卫了**马克思列宁毛主义**，并为围绕理论问题的两条路线斗争做出了相关贡献，特别是对当代**普拉昌达主义**、**阿瓦基安主义**和右倾机会主义路线“秘鲁人民解放运动”（LOD-Perú）修正主义的新论点做出了新的回击，这些修正主义观点的根源在于旧的托洛茨基主义谬论以及赫鲁晓夫、邓小平修正主义。公开的两条路线斗争在2022年继续，并随着**国际毛主义统一会议**（CIMU）的历史性实现和**国际共产主义者同盟**（ICL）的成立而上升到更高的水平。巴西共产党对这次历史性国际会议上达成的意识形态原则给予了深刻而广泛的支持，并对共产主义工人联盟（马列毛主义）和意大利毛主义共产党的攻击作出了有力的回应，这些攻击具有21世纪新修正主义的显着特征，并且针对创立国际共产主义者同盟的政党和组织。此外，它还提出了解决世界无产阶级革命的未决问题和新问题的方案。

通过与这些修正主义模式划清界限，**巴西共产党**全面捍卫了矛盾规律——这一唯物辩证法唯一的基本规律，并对1964年至1965年中国哲学战线大论战的重要意义进行了回顾——在那场大辩论中，左派的毛主义者坚持“一分为二”的哲学原则——从而阐明了马克思对“否定之否定”的运用与**毛主席**完全确立的对立统一规律之间的关系。同时，它揭示了尽管**阿瓦基安**和**普拉昌达**的哲学谬论之间存在明显的差异，但它们具有共同的资产阶级本质。因此，这篇文章证实了共产主义工人联盟（马列毛主义）与”合二而一“的修正主义哲学原则的趋同性。

该文件还对**新民主主义革命**的有效性进行了重要的分析和辩护，对帝国主义时代资本主义在殖民地和半殖民地国家农村的渗透进行了深入的讨论。它以清晰的方式阐明了伟大的列宁在俄国革命过程中对土地和农民问题的理解的进步，强调了农民在1905年革命中的出色参与对于布尔什维克土地纲领的修改具有决定性作用；这些发展对十月社会主义革命的彻底胜利至关重要。因此，它揭露了独立工人阶级（马列毛主义）所捍卫的阿瓦基安主义论点，即所谓的帝国主义“进步趋势”会“扫除半封建关系”。

**巴西共产党**从**贡萨罗主席**定义和发展的**毛主义**观点出发，揭示了帝国主义如何在殖民地和半殖民地国家催生官僚资本主义，通过其形式的演变维持潜在的半封建生产关系，而这种条件是维持其对被压迫人民和国家的帝国主义统治的必要条件。因此，它揭示了托洛茨基主义观念的内容以及**阿瓦基安主义**、共产主义工人联盟(马列毛主义)和意大利毛主义共产党的提法中存在的其他修正主义论点，这些提法低估了半封建制度演变的重要性，甚至通过陈述相反的观点将其抛弃，即帝国主义统治将扫除半封建制度。通过这种方式，他们贬低了**新民主主义革命**对帝国主义时代，尤其是当今世界无产阶级革命的重要性。

此外，**巴西共产党**敏锐地分析了帝国主义利润最大化与半殖民地国家和这些国家农民土地租金的特殊性之间的关系。该文件从对马克思主义土地租金理论的清晰解释出发，证明了农民的土地租金以及被压迫民族出口的农产品和矿产品与资本主义土地租金不一致，从而揭示了半封建生产和剥削关系通过其形式的演变而得以维持的过程。它发展了**毛主义**对帝国主义、官僚资本主义和半封建主义之间关系的理解，在新的层面上支持了巴西共产党政治宣言和原则中提出的论点，即被压迫民族和人民与帝国主义之间的矛盾是当今时代主要的基本矛盾。英勇的巴勒斯坦民族抵抗运动有力地证实了这一结论，它再次将民族解放问题和从地球上扫除帝国主义和所有反动派的斗争置于全球辩论的中心。

**巴西共产党**以**统一国际毛主义会议**所取得的成就为基础，以“**团结在毛主义的旗帜下！**”的口号为中心组建国际共产主义联盟所取得的巨大成功表明，在今天，是否支持新民主主义革命的普遍有效性、是否承认在所有殖民地和半殖民地国家通过不间断地开展**新民主主义革命**走向社会主义的唯一道路，是区分**毛主义者**和一小撮**假毛主义者**（即隐藏在毛主席革命思想虚伪辩词背后的修正主义者）的试金石。无论是**毛主义**共产党通过**秘鲁**、**印度**、**土耳其**和**菲律宾**的**人民战争**领导的当前革命，还是被压迫国家占世界面积绝大多数、地球人口绝大多数的事实，都表明并证实了**新民主主义革命**是世界无产阶级革命的主要力量，而以毛主义者为首的国际共产主义运动是它的领导力量。
因此，**巴西共产党**的这份文件推动了**国际共产主义运动**中两条路线斗争的新阶段，其不可或缺的翻译，特别是翻译成西班牙语，并尽快翻译成英语，将极大地有助于提升这场辩论，同时也将更清晰地划清毛主义与修正主义的界限。
